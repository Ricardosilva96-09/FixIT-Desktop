FixIT Desktop 1.2.1 Beta
Developed by Ricardo Silva, FixIT Desktop brings Windows diagnostics and maintenance tools together in a clean desktop interface.

Features
Health Score: evaluates available security, updates, disk space and Windows integrity data, with scan coverage shown separately.
Smart Scan: checks Windows protection, pending updates, device errors, temporary files, empty folders, broken shortcuts and recent error events.
Guided fixes: offers actions based on scan results, with confirmation, progress and revalidation.
Startup Manager: enables or disables supported startup entries and provides recommendations with source links.
Cleanup tools: removes eligible temporary files, selected empty folders and broken shortcuts. Shortcut targets can also be repaired manually.
Windows Repair: provides explained DISM and SFC commands, with administrator checks and output.
Diagnostics: includes hardware, storage, network, battery, printers, OneDrive, shared folders, VPN and Windows events, where accessible.
Reports: saves scan history and exports JSON, HTML or printable reports.
Settings: supports Portuguese and English, interface scaling and configurable refresh intervals.
Reliability improvements
Fixed drive-root handling during folder scans.
Improved protection against overlapping maintenance operations.
Invalidated outdated Health Scores after changes.
Strengthened report validation, cleanup boundaries and correction-plan checks.
Getting started
Download FixIT_Desktop_RicardoSilva_v1.2.1.zip below.
Extract the entire archive.
Open FixIT.Desktop.exe.
Keep the included runtime folder alongside the executable. No Python or separate .NET installation is required on supported systems.

Requirements: Windows 10/11, 64-bit. Some features require administrator privileges.

Beta status and testing
This release passed 63 automated checks, including simulated startup changes, cleanup safeguards, report handling and native shortcut repair using test files.

Real Windows repairs, update installation and changes to existing startup applications were not performed during validation. Some diagnostic queries could not be fully verified because of access restrictions in the test environment.

Unavailable data is marked as unconfirmed. A high Health Score with partial coverage does not mean the entire computer has been verified.

Drivers are not installed automatically. Maintenance actions require confirmation, and Windows restarts are not forced.

The application includes source code and local documentation. It is not digitally signed with a trusted code-signing certificate, so Windows may display security warnings.

Please report issues with your Windows version, the affected feature and any error message. Remove personal information before sharing reports.
